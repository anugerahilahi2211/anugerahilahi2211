## Featured Projects

### 1. PID-Controlled Thermoelectric Cooling System
**ESP32 · PID Control · Ziegler–Nichols · DS18B20 · Peltier TEC · MQTT**

Designed and implemented an ESP32-based thermoelectric cooling system for cold brew extraction. The system used closed-loop PID control, open-loop system identification, Ziegler–Nichols tuning, sensor calibration, and experimental evaluation at multiple temperature setpoints.

Repository:  
`cold-brew-pid-cooling-system`

### 2. ESP32-CAM Smart Warehouse Monitoring
**ESP32 · ESP32-CAM · IoT · Telegram Bot · HTTP · Web Monitoring**

Developed a dual-ESP32 monitoring architecture integrating smoke, flame, and intrusion sensing with automatic actuator responses and ESP32-CAM image notifications through Telegram.

Repository:  
`esp32cam-smart-warehouse-monitoring`

---

### 3. EMG Movement Classification Using KNN
**ESP32 · EMG · Signal Processing · PSD · Z-Score · KNN · ESP-NOW**

Built an EMG acquisition and classification prototype using ESP32-based sampling, signal features, Z-score normalization, KNN classification, and ESP-NOW command forwarding for grip, wrist, and elbow movement classes.

Repository:  
`emg-knn-movement-classification`

---

### 4. Self-Balancing Warehouse Robot
**ESP32 · MPU9250 · PID/PD · Complementary Filter · NEMA 17 · Wi-Fi**

Collaborative self-balancing robot project using an inverted-pendulum control approach, MPU9250 sensor fusion, stepper motors, and Wi-Fi-based movement control.
